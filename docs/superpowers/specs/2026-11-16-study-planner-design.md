# 공부 기록장 (아이패드 웹앱) 설계

작성일: 2026-11-16
시안: https://claude.ai/artifact/WwKzxLqFuDLbBQ9GqxJULp

## 왜 만드는가

사용자는 고등학생이고 대성마이맥과 메가스터디 인강을 듣는다. 하루를 시간 단위로 놓고 **무엇을 할지 계획**하고, **실제로 무엇을 했는지 기록**해서 둘을 비교하고 싶어 한다. 인강은 강좌별 **진도율**을 한눈에 보고 싶어 한다. 주로 아이패드에서, 사파리의 "홈 화면에 추가"로 앱처럼 쓴다.

## 목표

1. 하루 시간표에 계획을 넣는다. 계획 하나는 시간 범위와 내용으로 이루어진다. 내용은 등록한 강좌의 "몇 강부터 몇 강까지"이거나, 자유 텍스트(예: "기출 풀이 수학 20문제")다.
2. 실제로 한 것을 두 가지 방법으로 기록한다. 사용자가 둘 다 원했다.
   - **타이머**: 시작할 때 무엇을 하는지 고르고 시작을 누르고, 끝날 때 멈춘다. 멈추면 실제 기록 블록이 생긴다.
   - **직접 입력**: 나중에 시간표의 빈칸을 눌러 채운다.
3. 계획과 실제를 나란히 보여 준다. 그날의 계획 시간, 실제 시간, 달성률을 맨 위에 표시한다.
4. 강좌를 등록한다(강좌명, 총 강 수). 강의를 들었다고 체크하면 진도율(들은 강 수 / 총 강 수)이 자동으로 계산된다.
5. **인강 화면 캡처로 강좌 등록**: 사용자가 마이맥이나 메가스터디의 강의 목록 캡처를 올리면, 앱이 아이패드 안에서 글자를 읽어 강좌명과 강의 목록(총 강 수)을 뽑아낸다. 결과를 바로 저장하지 않고, 사용자가 확인하고 고치는 화면을 거친다.
6. 계획했지만 못 한 강의나 할 일은 표시해서 다음 날 계획에 쉽게 다시 넣을 수 있게 한다.

## 하지 않을 것

- 마이맥이나 메가스터디와의 진짜 연동(로그인해서 수강 기록 자동 가져오기). 공개 API가 없고, 계정 정보를 앱에 넣는 건 위험하다.
- 돈이 드는 것. 유료 API(Claude, OpenAI 등)나 유료 호스팅은 쓰지 않는다. 사용자가 분명히 "돈 없이"라고 했다.
- 회원가입, 로그인, 서버, 여러 기기 동기화.

## 실패로 보는 것

- 기록하는 데 손이 너무 많이 가서 공부보다 기록이 귀찮아지는 것. 자주 하는 동작(타이머 시작·정지, 강의 완료 체크)은 탭 한두 번으로 끝나야 한다.
- 캡처 인식 결과가 확인 없이 저장되어 강좌 데이터가 엉망이 되는 것.
- 데이터가 말없이 사라지는 것.

## 정해진 방식

- **아이패드 사파리에서 홈 화면에 추가해 쓰는 웹앱**(사용자 결정).
- **비용 0원**(사용자 결정).
- 캡처 글자 인식은 **브라우저 안에서 도는 무료 OCR**로 한다(사용자 결정). 한글 인식이 완벽하지 않다는 점은 사용자에게 설명했고, 그래서 확인·수정 화면이 필수다.

## 내가 정한 것 (Claude의 판단, 사용자 확인 전)

- **화면 구성**: 시안처럼 아이패드 가로 기준으로 왼쪽에 시간표(계획 | 실제 두 열), 오른쪽에 강좌 진도 목록, 맨 위에 날짜 이동과 오늘 요약. 세로 화면이나 좁은 화면에서는 한 열로 쌓는다.
- **시간 단위**: 30분 칸. 기본 표시 범위는 06:00~24:00, 설정에서 바꿀 수 있다. 블록은 칸에 맞춰 붙되 타이머 기록은 실제 분 단위 시간을 그대로 저장한다.
- **기술**: 빌드 도구 없이 HTML·CSS·JavaScript로 만든다. 웹 앱 매니페스트와 서비스 워커를 넣어 홈 화면 아이콘과 오프라인 동작을 지원한다.
- **저장**: 아이패드 안 브라우저 저장소(IndexedDB). 서버 없음.
- **백업**: 사파리는 오래 안 쓴 사이트 데이터를 지울 수 있어서, 전체 데이터를 JSON 파일로 내보내고 다시 불러오는 기능을 넣는다. 일주일 넘게 백업을 안 했으면 조용히 알려 준다.
- **호스팅**: GitHub Pages(무료, HTTPS). 홈 화면에 추가하려면 HTTPS 주소가 필요하다.
- **OCR**: Tesseract.js와 한국어 학습 데이터. 처음 한 번 내려받은 뒤 캐시한다(수 MB).
- **타이머**: 시작 시각만 저장해 두고 경과 시간은 계산한다. 그래서 앱을 닫았다 열어도 타이머가 이어진다.
- **강좌 정보**: 강좌명, 플랫폼(마이맥 / 메가스터디 / 기타), 선생님(선택), 총 강 수, 강의별 제목(캡처에서 읽었을 때만), 강의별 완료 여부.
- **달성률**: 그날 계획 블록 시간 중 같은 내용으로 실제 기록된 시간의 비율. 강의 계획은 계획한 강 중 완료한 강의 비율로 센다.
- **화면 언어**: 한국어.
- **계획과 실제 연결**: 타이머를 시작하거나 빈칸을 채울 때, 먼저 오늘 계획 목록이 뜨고 하나를 탭하면 그 계획에 연결된다. 계획에 없는 걸 했으면 "기타"를 고르고 강좌나 자유 텍스트를 입력한다. 실제 블록은 연결된 계획을 기억하고, 달성률은 이 연결로만 계산한다(글자 비교는 하지 않는다).
- **강의 완료 처리**: 강의 계획에 연결된 기록을 끝내면(타이머 정지 또는 직접 입력 저장) 계획한 강의들이 체크된 상태로 뜬다. 다 들었으면 확인만 누르고, 못 들은 강만 체크를 해제한다. 강좌 목록에서도 따로 체크할 수 있다.
- **못 한 것 넘기기**: 못 들은 강의와 못 한 할 일만 "밀린 것" 칸에 쌓인다(예: 3~5강 계획에서 4강까지 들었으면 5강만). 다음 날 자동으로 배치하지는 않고, 사용자가 밀린 것 칸에서 골라 시간표에 넣는다.
- **캡처 여러 장**: 강의가 많아 한 화면에 안 들어가는 강좌는 캡처를 여러 장 올릴 수 있다. 강 번호 기준으로 합치고 중복은 하나로 친다. "1-1강", OT, 보충강처럼 애매한 항목은 확인 화면에서 포함할지 고르게 한다. 실제 캡처 샘플은 구현할 때 사용자에게 받는다.

## 빌더에게 맡기는 것

- 코드 구조, 파일 나누기, 세부 디자인(색, 글꼴, 애니메이션). 시안의 분위기는 유지한다.
- 캡처에서 강의 번호와 제목을 찾아내는 규칙(예: "1강", "01." 같은 패턴). 마이맥과 메가스터디 화면에 맞춰 조정하되, 결과는 항상 확인 화면을 거친다.
- 계획 블록 드래그로 옮기기 같은 편의 기능의 범위.

## v2 (2026-11-16): 종이 스터디 플래너

사용자가 첫 화면과 파스텔 카드 시안을 "AI 디자인 같다"고 했고, 두 방향 시안 중 **종이 스터디 플래너**를 골랐다.

- 화면: 위에 DATE / D-DAY / TOTAL / 달성 / MEMO 칸. 왼쪽에 PLAN 목록(○ 다 함, △ 덜 함, ✕ 못 함), 밀린 것, LECTURE(한 강 = 한 칸). 오른쪽에 10분 칸 TIME TABLE을 과목별 형광펜 색으로 칠한다. 계획 시간은 칸 아래 색 띠로 보인다.
- **과목별 색**(사용자 요청): 강좌와 할 일마다 과목을 고르고, 설정에서 과목 이름과 형광펜 색을 바꾼다. 기본 과목은 국어·수학·영어·탐구·기타.
- **선생님 프로필**(사용자 요청): 강좌마다 사진을 고르고 네모(증명사진 비율)에 맞춰 잘라 저장한다. 사진이 없으면 이름 두 글자.
- Claude의 판단: 계획은 시간표 칸 대신 목록으로, 시간 단위는 10분으로 바꿨다. D-day와 하루 메모 칸을 추가했다. 글꼴은 Gowun Dodum과 IBM Plex Mono.
